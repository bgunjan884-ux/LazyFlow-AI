# 🦥 LazyFlow AI — Slow & Steady

### Let the sloth do the work. Take life at your own pace.

LazyFlow AI is a simple, sloth-themed productivity assistant designed to make everyday tasks easier. It helps users create to-do lists, draft polite messages, organize their thoughts, and plan relaxing activities without unnecessary effort.

Built using **HTML, CSS, and JavaScript**, LazyFlow AI features a demo mode and an optional integration with **Ollama**, allowing users to run an open-weight AI model locally on their computer.

The goal is simple: spend less time struggling with small tasks and more time doing what matters.

---

## 🌿 The Problem

We all have small tasks that we keep putting off—writing messages, organizing our day, deciding what to do next, or planning time to relax.

These tasks may seem simple, but they can take up time and energy.

LazyFlow AI offers a calmer approach by turning everyday requests into simple plans, useful drafts, and manageable next steps.

## ✨ Features

- 📝 **Smart Task Assistance:** Turn everyday requests into simple, manageable steps.
- 📋 **To-Do List Suggestions:** Get a starting point for organizing daily tasks.
- 💬 **Message Drafting:** Create polite reminders and message drafts.
- 🌱 **Relaxation Planner:** Discover simple ideas for a slower, more relaxing evening.
- 🤖 **Local AI Integration:** Optionally connect to an open-weight model through Ollama.
- 📋 **Copy Results:** Copy generated suggestions for later use.
- 🧹 **Clear Function:** Clear your task and start again.
- 🎨 **Calming Interface:** Enjoy a clean, nature-inspired design with a sloth theme.
- 📱 **Responsive Design:** Use the interface on desktop and mobile screens.
- 🧪 **Demo Mode:** Try sample responses even before configuring a local AI model.

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|

| Ollama | Optional local AI model runner |

## 🚀 How to Run the Project

### Step 1: Download the Project

Download or clone the repository to your computer.

### Step 2: Open in VS Code

Open the project folder in Visual Studio Code.

### Step 3: Run the Website

Install the Live Server extension if necessary.

Right-click `index.html` and select **Open with Live Server**.

The website will open in your browser, and you can try the example prompts.
